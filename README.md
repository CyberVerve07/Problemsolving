## 💡 Code Highlights

<details>
<summary><b>🔷 Factory Pattern — Clean Interface-Based Design</b></summary>

```java
// Product Interface — defines the contract
public interface Payment {
    void pay(double amount);
}

// Concrete Product — PayPal implementation
public class PayPalPayment implements Payment {
    @Override
    public void pay(double amount) {
        System.out.println("Processing PayPal payment of $" + amount + " [SUCCESS]");
    }
}

// Factory — encapsulates object creation logic
public class PaymentFactory {
    public static Payment createPayment(String type) {
        return switch (type.toUpperCase()) {
            case "CREDIT"  -> new CreditCardPayment();
            case "UPI"     -> new UPIPayment();
            case "PAYPAL"  -> new PayPalPayment();
            default        -> throw new IllegalArgumentException("Unknown: " + type);
        };
    }
}
```

</details>

<details>
<summary><b>🔷 Stream API — First Non-Repeating Character</b></summary>

```java
Character firstNonRepeating = input.chars()
    .mapToObj(c -> (char) c)
    .filter(c -> !Character.isWhitespace(c))
    .collect(Collectors.groupingBy(
        Function.identity(),
        LinkedHashMap::new,       // Preserves insertion order
        Collectors.counting()
    ))
    .entrySet().stream()
    .filter(entry -> entry.getValue() == 1)
    .map(Map.Entry::getKey)
    .findFirst()
    .orElse(null);
```

</details>

<details>
<summary><b>🔷 Multithreading — Deadlock Detection</b></summary>

```java
// Thread 1 locks Resource A → waits for Resource B
// Thread 2 locks Resource B → waits for Resource A
// Result: DEADLOCK — both threads block forever

new Thread(() -> {
    synchronized (resourceA) {
        System.out.println("Thread-1: locked Resource A");
        synchronized (resourceB) {
            System.out.println("Thread-1: locked Resource B");
        }
    }
}).start();

new Thread(() -> {
    synchronized (resourceB) {
        System.out.println("Thread-2: locked Resource B");
        synchronized (resourceA) {
            System.out.println("Thread-2: locked Resource A");  // 💀 Never reached
        }
    }
}).start();
```

</details>

- **Java 21** or later — [Download from OpenJDK](https://openjdk.org/)
- **IntelliJ IDEA** (recommended) or any Java-compatible IDE

### Clone & Run

```bash
# 1. Clone the repository
git clone https://github.com/CyberVerve07/Problemsolving.git
cd Problemsolving

# 2. Compile and run any Java file
javac -d bin src/DesignPattens/factory/PaymentDemo.java
java -cp bin DesignPattens.factory.PaymentDemo

# 3. Or simply open in IntelliJ IDEA and run any file with main()
```

> **💡 Tip:** Every `.java` file contains its own `main()` method — just right-click and run in your IDE.
